# KAIROS - Administração Inteligente de Gôndolas

Uma plataforma para otimizar a gestão de gôndolas em supermercados por meio de monitoramento em tempo real, análise de dados e inteligência artificial.

## Sobre o projeto

O KAIROS nasce para enfrentar um problema comum no varejo: a ruptura de estoque nas gôndolas, que prejudica vendas e a experiência do cliente. A proposta é criar uma solução que conecte repositores, vendedores, clientes e gerentes em um mesmo fluxo de informação, permitindo identificar rapidamente quando um produto precisa ser reposto, registrar todo o histórico dessa operação e transformar esses dados em insights estratégicos para a gestão da loja.

## Objetivo

Desenvolver uma plataforma que reduza rupturas de estoque nas gôndolas, agilize a reposição, gere histórico operacional e forneça insights estratégicos para gestores.

## Funcionalidades

- Alertas de reposição em tempo real para repositores
- Registro do histórico de reposições via leitura da gôndola
- Cadastro de vendas fornecendo histórico
- Painéis analíticos para gerentes
- Recomendações inteligentes baseadas em demanda

## Perfis de usuário

| Perfil | O que faz |
|---|---|
| **Repositor** | Recebe alertas, escaneia a gôndola após a reposição e registra data, hora e histórico para rastreabilidade. |
| **Vendedor/Caixa** | Pode cadastrar opcionalmente o e-mail do cliente durante a compra, vinculando as compras ao perfil do consumidor para análises futuras. |
| **Cliente** | Visualiza produtos favoritos, promoções, descontos e queimas de estoque com base no histórico de compras. |
| **Gerente** | Mapeia as gôndolas da loja durante o cadastro, administra vendedores e repositores (CRUD), acompanha dashboards, identifica produtos mais vendidos e utiliza um chatbot especialista para recomendações de investimento em estoque. |

## Como funciona (fluxo geral)

1. O gerente cadastra a loja e as gôndolas.
2. O sistema monitora a necessidade de reposição.
3. O repositor recebe o alerta e confirma a reposição por escaneamento.
4. O caixa associa as compras aos clientes (opcional).
5. O sistema consolida os dados e gera insights.
6. O cliente recebe ofertas personalizadas.
7. O gerente consulta dashboards e o chatbot.

## Diferenciais

- Histórico completo de reposições
- Marketing personalizado
- Decisões orientadas por dados
- Redução de ruptura de estoque
- Melhor experiência do cliente
- IA para apoio estratégico
